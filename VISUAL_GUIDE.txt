================================================================================
                    HOW TO SEE STUDENTS UNDER INSTRUCTORS
================================================================================

STEP 1: Start Server
---------------------
Open terminal/command prompt and run:
    python manage.py runserver


STEP 2: Open Browser
---------------------
Go to: http://127.0.0.1:8000/admin/


STEP 3: Login
-------------
Username: admin
Password: admin123


STEP 4: Go to Analytics
------------------------
After login, in the URL bar type:
    http://127.0.0.1:8000/admin/analytics/

OR click on "View site" then add "/admin/analytics/" to the URL


STEP 5: You Should See This
----------------------------
At the TOP of the page, you'll see a box with buttons:

    ┌─────────────────────────────────────────────────────┐
    │              Quick Access                            │
    ├─────────────────────────────────────────────────────┤

    │  [👤 Manage Users]                                   │
    │  [📖 Manage Courses]                                 │

STEP 6: Click First Button
---------------------------
Click on: [👨🏫 Students by Instructor]

This takes you to: http://127.0.0.1:8000/manage/instructor-students/

================================================================================
                            TROUBLESHOOTING
================================================================================

Problem: I don't see the buttons
Solution: Make sure you're at /admin/analytics/ NOT just /admin/

Problem: I get an error
Solution: Make sure server is running and you're logged in

Problem: No data shows
Solution: Run: python manage.py shell < seed_complete.py

Problem: Page not found
Solution: Check the URL is exactly: http://127.0.0.1:8000/admin/analytics/
